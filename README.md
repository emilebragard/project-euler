# Project Euler Solutions

These are my solutions to the first 100 problems from [Project Euler](https://projecteuler.net/), implemented in various programming languages including Python and C++.

## Structure

Each problem is organized in its own directory with the problem number as the folder name (e.g., `1/`, `2/`, ..., `100/`).

## Usage

Navigate to the problem directory and run the solution:

```bash
cd 1
python main.py
# or
./main.exe
```
